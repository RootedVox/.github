# RootedVox 品牌与视觉设计指南

本文件记录了 RootedVox 核心视觉资产（Logo 及 Banner）的设计理念与代码实现思路。

## 🔣 Logo 设计理念：代码、权限与共鸣

RootedVox 的 Logo 并非单纯的几何图形，而是由几层深刻的“极客隐喻”交织而成的：

1. **Root 权限 (井号 `#`)**
   在 Unix/Linux 终端中，`#` 代表最高权限（Root）。它象征着 RootedVox 脱离官方体制的独立精神——在这个赛博空间里，我们拥有完全的自主权。
2. **代码注释 (双斜杠 `//`)**
   在绝大多数编程语言中，`//` 是注释符号。它代表着自由表达、记录与发声，没有任何门槛。
3. **共鸣的声波 (左右声纹)**
   贯穿画面的两条声纹，一左一右相互呼应。左边的声波先发声，右边的声波作为回应。这完美契合了“社区交流”的本质——发出你的声音，总有人会倾听并回应。
4. **视觉合成**
   两根绿色的斜杠（`//`），被两道横向延伸的声波（声纹）穿透，最终在视觉上合成了一个巨大的 **`#`（井号）**。

## 🎨 色彩规范 (Color Palette)

- **背景黑 (`#050a06`)**: 致敬终端 (Terminal) 的经典暗色背景。
- **终端绿 (`#33FF66` / `#5CFF8A`)**: 极客与活力的象征，代表代码的高亮与生机。
- **字标白 (`#F1F6F2`)**: 用于 `Rooted` 字样，代表扎根于底层的纯粹与稳定。

## 🎬 动效与 SVG 实现

我们的 Banner 使用纯 SVG 代码手写渲染（由 Anthropic Claude 辅助生成），没有使用任何外部图片素材。
- **声波动画**: 通过几百个 `<rect>` 矩形配合随机的 `animation-delay` 和 `scaleY()` 实现。
- **发光效果**: 使用 `<filter>` 中的 `feGaussianBlur` 实现霓虹光晕。
- **无障碍适配**: 内置了 `@media (prefers-reduced-motion: reduce)`，当用户设备开启“减弱动态效果”时，动画会自动停止，保障访问体验。
